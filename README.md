A Go-native workflow platform inspired by .NET's Windows Workflow Foundation 4
(WF4): an engine that runs, schedules, and persists workflow instances; a
built-in activity library; a planned plugin system for custom activities
distributed as OCI images; and a planned web-based drag & drop designer.

See [docs/README.md](docs/README.md) for the full project overview and the
three-phase project plan (epics and issues).

## Status

Phase 1 (core engine, built-in activities, persistence) is in progress. No
plugin system or designer UI yet.
